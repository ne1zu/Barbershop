# 💈 Barbershop CRM — Система управления барбершопом

Полноценная консольная CRM-система для автоматизации работы барбершопа, написанная на C++. Проект разработан в рамках курсовой работы с упором на **чистую архитектуру (Clean Architecture)**, принципы **SOLID** и паттерны проектирования.

## 🚀 Ключевые возможности (Бизнес-логика)

Система поддерживает 3 независимые роли пользователей с разграничением прав доступа (RBAC):

*   👨‍💼 **Администратор (Владелец / Менеджер):**
    *   Полный доступ к журналу записей, управлению персоналом и каталогу услуг.
    *   Проведение оплат, учет скидок лояльности, выдача чеков.
    *   Просмотр финансовой аналитики (выручка, средний чек, статистика отмен).
*   ✂️ **Мастер:**
    *   Просмотр личного расписания на день.
    *   Управление своими услугами (индивидуальные цены и длительность в зависимости от квалификации: *Junior, Standard, Top*).
    *   Изменение статусов визита (подтвержден, клиент пришел, неявка).
*   📱 **Клиент:**
    *   Регистрация и авторизация по номеру телефона (+375...).
    *   Ручная запись и **«Умный подбор времени»** (эвристический алгоритм, который подбирает лучшие слоты на основе цены, рейтинга мастера и минимизации "окон" в расписании).
    *   Система лояльности (статусы Bronze, Silver, Gold со скидками 5%, 10%, 15%).
    *   Отмена и перенос записей (с защитой от отмены менее чем за 2 часа до старта).

## 🛠 Технические особенности (Для ревьюера)

Проект спроектирован без использования антипаттерна *God Object*. Логика строго разделена на слои:

1.  **Domain (Сущности):** Абстрактный базовый класс `Person` с полиморфными методами (`classify`, `getPriceFactor`).
2.  **Custom STL-like Containers:** Написан собственный обобщенный шаблонный класс `Collection<T>`. Реализованы алгоритмы высшего порядка (`findAll`, `countIf`, `findFirst`), работающие через предикаты.
3.  **Exception Handling:** Создана иерархия из 14 собственных классов исключений (`BarbershopException`). Обработка ошибок централизована в слое UI (`menu_common.cpp`).
4.  **Value Objects:** Разработан независимый класс `DateTime`, инкапсулирующий математику гражданского календаря (високосные года, перевод в линейное время эпохи).
5.  **UI & Workflow Separation:** Низкоуровневая защита потока ввода (`std::cin`) вынесена в `console_input.cpp`, а сложные диалоги (например, процесс бронирования) изолированы в `booking_flow.cpp`.

## ⚙️ Сборка и запуск

Проект написан с использованием стандарта **C++17**. Никаких сторонних библиотек не требуется.

**Как запустить в Visual Studio:**
1. Создайте пустой проект «Консольное приложение C++».
2. Скопируйте папки `src` и `include` в папку проекта.
3. В Visual Studio нажмите иконку *«Показать все файлы»* (Show All Files), выделите папки `src` и `include` -> ПКМ -> *«Включить в проект»*.
4. Зайдите в **Свойства проекта**:
   * В разделе `C/C++ -> Общие` добавьте `$(ProjectDir)include` в *«Дополнительные каталоги включаемых файлов»*.
   * В разделе `C/C++ -> Язык` установите стандарт **C++17**.
5. Нажмите `F5` для компиляции и запуска.
